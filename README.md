作成物：自動生成される迷路を探索し、制限時間やスコアを意識しながら、より深い階層を目指す迷路ゲーム．

概要：プレイヤーは迷路のスタート地点から出発し，ゴールを目指す．迷路はプレイごとに自動生成され，ゴールに到達すると次のフロアに進む．

各機能：
・迷路：自動生成する
・スタートゴール：各フロアに設置
・プレイヤー：自分で動かすこととする（自動探索機能はなしの方向），キーボードからの操作とする
・ゲーム進行：ゴールするごとに上の階へ
・時間：タイマー機能を搭載し，制限を設ける．制限時間内にゴールできたら次のフロアへ行けることとする

発展機能：
・フロアが進むにつれて難易度が上昇
・敵を登場させて，逃げる必要がある迷路をつくる
・アイテム機能をつくる．具体的には，時間を延長できる，スコアが向上する，宝箱を設置しその鍵を出現させる等
